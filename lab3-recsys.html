Рекомендательные системы

История неявной обратной связи объединяется с NLP- и CV-признаками. Система ранжирует исследовательские идеи, затем применяет ограничения риск-профиля.

Постановка задачи

ОбъектИсследовательская идея по активу, а не команда купить или продать.
СигналыПросмотр, открытие анализа, сохранение и watchlist.
ОграниченияРиск, горизонт, доступность инструмента и пригодность.

Данные и временная схема

Учебный пример содержит 85 000 взаимодействий 2 400 синтетических профилей с 420 активами. Temporal leave-last-two оставляет предпоследнее событие для validation, последнее — для test. Негативы выбираются только из активов, доступных в момент события.

События
user, item, time
NLP
event, sentiment
CV
trend, embedding
Ranker
top-10 + evidence

Действия над данными

  1. Сформировать candidate set. Только инструменты, доступные на дату события.
  2. Построить baseline. Popularity, implicit ALS и BPR при едином наборе кандидатов.
  3. Обучить современные модели. NCF, LightGCN, SASRec, BERT4Rec и two-tower.
  4. Добавить мультимодальность. Замороженные NLP и CV embeddings входят только в item tower.
  5. Применить hard constraints. Недопустимый актив не может вернуться из-за высокого score.
  6. Оценить срезы. Warm-start, new item, short history и новостной шок.

После жесткого фильтра violations равны 0%. Risk-aware reranking снижает NDCG@10 до 0,312, но увеличивает coverage до 0,684. Потеря 0,006 принимается ради диверсификации.

Фрагмент кода ранжирования

candidates = available_assets(event_time)
candidates = hard_filter(candidates, user.risk, user.account_type)

item_vector = concat(id_embedding, nlp_embedding, cv_embedding)
scores = two_tower(user.history, item_vector)
top50 = rank(scores)
top10 = risk_aware_rerank(top50, coverage_target=0.55)

assert count_violations(top10, user.profile) == 0
return attach_evidence(top10)

Результат: ограничения выполняются до и после ранжирования, а каждая идея сохраняет доказательный фрагмент и версии NLP/CV-признаков.

Выводы

Мультимодальные признаки дают наибольший вклад для новых и редко взаимодействовавших активов. Последовательные модели сильнее ALS на активных пользователях, но при истории короче трех событий ALS устойчивее. Ограничения пригодности имеют приоритет над predicted score.
