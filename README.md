# PML — демонстрационные лабораторные работы

Интерактивный учебный сайт для дисциплины «Прикладные задачи машинного обучения».

- Лабораторная 1: NLP-анализ финансовых новостей.
- Лабораторная 2: CV-анализ финансовых графиков.
- Лабораторная 3: мультимодальное ранжирование инвестиционных идей.
- Лабораторная 4: сквозной проект, абляции и воспроизводимость.

Для лабораторной 1 добавлены браузерный просмотр 52 слайдов, обновленная презентация, подробный текст лектора и исходный текст задания.

Сайт публикуется через GitHub Pages. Численные результаты на страницах являются учебными примерами из методических материалов и должны быть заменены результатами собственных экспериментов студентов.
