Постановка задачи

ВходЗаголовок и текст финансовой новости, дата и источник.
Выходticker, entity, event, sentiment, confidence, evidence, abstain.
РешениеПередать проверяемые признаки в ранжирование инвестиционных идей.

Выход не является инвестиционной рекомендацией. Модель структурирует наблюдение, сохраняет доказательный фрагмент и может отказаться от ответа при недостаточной уверенности.

Данные

Основной наборFinancial PhraseBank на Kaggle. Финансовые фразы с тональностью.
Временной контекстИстория рынка связывается с датой новости только после временного разбиения.
Защита от утечкиДубликаты одного события и одного заголовка остаются в одной части.

Действия над данными

  1. Разделить по времени. Train формируется раньше validation и test. Все преобразования обучаются только на train.
  2. Нормализовать без потери смысла. Сохраняются числа, проценты, валюты, отрицания, тикеры, знаки плюс и минус.
  3. Разметить сущности. Слабая разметка по справочнику дополняется ручной проверкой стратифицированной выборки.
  4. Зафиксировать токенизацию. Сравниваются BPE и SentencePiece, длина последовательности и доля усечения.
  5. Оценить единым протоколом. Macro-F1, entity-F1, ECE, p95 и валидность JSON считаются на одном test.

Правило выбора: 55% Macro-F1, 20% entity-F1, 10% калибровка, 10% задержка, 5% валидный JSON. Qwen2.5-7B выбирается для пакетного исследовательского прототипа. FinBERT + RuBERT-NER остается быстрым интерактивным вариантом.

Фрагмент кода эксперимента

schema = {
  "ticker": str, "event": str, "sentiment": int,
  "confidence": float, "evidence": str, "abstain": bool
}

split = temporal_split(events, group_by="event_id")
model.fit(split.train)
pred = validate_json(model.predict(split.test), schema)

metrics = {
  "macro_f1": f1_score(y_true, pred.sentiment, average="macro"),
  "entity_f1": entity_level_f1(spans_true, pred.spans),
  "ece": expected_calibration_error(y_true, pred.proba),
  "p95_ms": percentile(latency_ms, 95)
}

Результат: код фиксирует временное разбиение, проверяет структуру генерации и считает качество вместе с калибровкой и задержкой.

Выводы

Гипотеза H1 подтверждается в учебном примере. Предметные и генеративные модели превосходят общий encoder-baseline, но прирост Qwen2.5-7B сопровождается почти девятикратным ростом p95 относительно FinBERT.
