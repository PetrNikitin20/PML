Итоговый проект

Сквозная система объединяет данные, NLP, CV, рекомендации, ограничения и интерфейс. Абляции показывают измеримый вклад каждого компонента.

Критерий завершенностиРезультат воспроизводимДругой исследователь запускает сценарий и получает ключевую таблицу
Главный принцип: исследовательский вклад формулируется как проверенный эффект интеграции и границы переноса, а не как факт использования нескольких моделей.

Постановка итоговой работы

Система собирает новости и цены, извлекает сущности и события, анализирует графики, формирует допустимых кандидатов и ранжирует исследовательские идеи с учетом риск-профиля.

Основная гипотезаFull pipeline превосходит сильный baseline по NDCG@10 при приемлемой задержке.
Абляционная гипотезаУдаление компонента дает интерпретируемое снижение на конкретном срезе.
БезопасностьReranking устраняет критические нарушения при потере NDCG не более 0,01.

Действия итогового эксперимента

  1. Заморозить test. До финального сравнения не использовать его для выбора модели.
  2. Зафиксировать lineage. Dataset, features, model, code commit и environment lock.
  3. Сравнить full и baseline. Один candidate set и одинаковый протокол.
  4. Провести абляции. Without NLP, CV, history, constraints и calibration.
  5. Проверить отказ. При недоступности тяжелой модели включается безопасный fallback.
  6. Подготовить артефакты. Datasheet, model card, risk register и сценарий демонстрации.

Итоговые выводы

Основной вариант full + reranking принимается. NDCG@10 ниже чистого fusion на 0,006, но coverage выше на 0,043, а нарушения отсутствуют. NLP дает основной прирост для событийных идей, CV помогает при нейтральном тексте и новых активах, fallback сохраняет безопасный список при отказе компонента.
